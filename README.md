# Семейный бюджет — Telegram Mini App + Google Таблица

Мини-приложение для учёта доходов и расходов семьи: ввод операций с телефона, остатки по кошелькам, план-факт по статьям, ОДДС.

- **Интерфейс** — `index.html` (GitHub Pages), открывается кнопкой в Telegram-боте.
- **Данные** — Google Таблица на вашем Диске (листы Журнал, Остатки, План-факт, ОДДС, Бюджет, Статьи, Кошельки, Контрагенты, Доступ).
- **Сервер** — `apps-script/Code.gs` (Google Apps Script, бесплатно). Проверяет подпись Telegram и список доступа.

В репозитории нет ни данных, ни токенов — только код. Демо: откройте страницу с `?demo=1`.

## Настройка (≈10 минут, один раз)

### 1. Таблица и скрипт
1. Откройте Google Таблицу «Семейный бюджет» → **Расширения → Apps Script**.
2. Удалите содержимое `Код.gs`, вставьте весь текст из `apps-script/Code.gs`, нажмите 💾.
3. Вверху выберите функцию **setup** → **Выполнить**. Google попросит доступ — разрешите
   («Дополнительно → Перейти к проекту»; это ваш собственный скрипт).
4. Вернитесь в таблицу (обновите вкладку) — появится меню **💰 Бюджет** и все листы.
5. Если учёт начинаете со следующего месяца: **💰 Бюджет → 0. Начать учёт с месяца…** (например `2026-12`).
   Ранние месяцы уберутся из «Бюджета», останется 12 месяцев начиная со стартового.
6. На листе **Кошельки** впишите начальные остатки на 1-е число стартового месяца.

> В Apps Script должен быть **только один** файл `.gs` с этим кодом. Если рядом остался старый файл,
> он перекрывает новые функции. Проверка: **💰 Бюджет → О скрипте** показывает версию кода.

### 2. Бот
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → получите токен.
2. В таблице: **💰 Бюджет → 2. Указать токен бота** → вставьте токен.
   Токен хранится только в настройках скрипта, никому его не пересылайте.

### 3. Публикация API
1. В Apps Script: **Начать развёртывание → Новое развёртывание** → тип **Веб-приложение**.
2. «Выполнять как» — **Я**, «У кого есть доступ» — **Все** → **Развернуть**.
   (Доступ «Все» безопасен: без подписи Telegram от вашего бота и галочки в листе «Доступ» скрипт ничего не отдаёт.)
3. В таблице: **💰 Бюджет → 3. Подключить приложение к боту**. Если спросит адрес — вставьте URL веб-приложения (заканчивается на `/exec`).

### 4. Доступ для семьи
1. Откройте бота в Telegram → кнопка **«Бюджет»** слева от поля ввода.
2. Приложение покажет «Нужен доступ» и добавит вашу строку на лист **Доступ**.
3. Поставьте галочку **Разрешён** → в приложении нажмите «Обновить». То же самое — для второго члена семьи.
4. По желанию заполните «Группа по умолчанию» и «Кошелёк по умолчанию».

## Как пользоваться

| Где | Что |
|---|---|
| Приложение | Ввод операций (расход / доход / перевод), главная с остатками, лента, план-факт, ОДДС за месяц / квартал / год |
| Приложение → «План» | Нажмите на статью — изменить план: только на этот месяц, до конца года или на 12 месяцев вперёд. «＋ Новая статья» — статья с планом (можно в новой группе). «Взять план …» — скопировать план прошлого месяца. Недостающие месяцы добавляются в лист «Бюджет» сами |
| Приложение → «Обзор» | Кошельки: создать, переименовать, задать начальный остаток, скрыть |
| Приложение → «План» → статья → «Изменить или удалить статью» | Переименовать, сменить группу и иконку (больше 160 смайликов или свой), скрыть. Статью без операций можно удалить; при переименовании операции в журнале переименуются вместе с ней. Скрытые — кнопка «Скрытые (N)» |
| Приложение → операция | Нажмите на операцию — изменить; внизу «Удалить операцию». Поле «Кто платил» подставляется по владельцу карты, можно переключить; в журнале это столбец «Кто платил». Отчёт «Кто сколько заплатил» считается по нему |
| Приложение → «ОДДС» → «По кошелькам» | Движение по каждому кошельку: начало, поступления, расходы, переводы, конец и на что тратили — видно, кто платил |
| Приложение → «Операции» | Поиск по статье, контрагенту, комментарию, кошельку, кто платил, сумме (несколько слов — всё должно совпасть), за месяц или за всё время; фильтр по типу и кошельку. В выборе статьи — тоже поиск |
| Приложение → «ОДДС» → «Сводная» | Статьи × кошельки с итогами. Нажмите на сумму — откроется список операций; из него можно открыть операцию и вернуться стрелкой «назад» |
| Лист «Статьи» | Добавить/переименовать статьи, иконку (эмодзи), выключить ненужные |
| Лист «Бюджет» | План по статьям на каждый месяц |
| Лист «Кошельки» | Карты/счета/наличные и начальные остатки |
| Лист «План-факт» | Выберите месяц в ячейке B2 |
| Приложение → «План» → «Сделать один список» | Убирает группы Люся / Кирилл / Общие: одинаковые статьи объединяются, план суммируется, операции в журнале переходят на объединённые статьи. То же в таблице: меню «💰 Бюджет → Убрать группы статей» |
| Меню «💰 Бюджет» | **Обновить отчёты** — после ручного изменения статей или кошельков в таблице; **Добавить месяц…** — любой месяц (встанет по порядку); **Добавить 12 месяцев** — продлить бюджет |

Операции можно вносить и прямо в лист «Журнал» (есть выпадающие списки) — приложение их подхватит.

## Если поменяли код скрипта
В Apps Script: **Развертывания → Управление развертываниями → ✏️ → Версия: новая → Развернуть**. URL не меняется.
